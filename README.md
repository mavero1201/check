# Survey QA AI

Веб-сервис для автоматической проверки количественных анкет с позиции маркетингового исследователя.

## Что делает продукт

Пользователь загружает документ с анкетой через drag-and-drop интерфейс. Система извлекает текст анкеты, запускает AI-проверку и возвращает структурированный отчет с замечаниями, рисками и рекомендациями.

## Ключевая ценность

Продукт экономит время исследовательской команды на первичной методологической проверке анкеты и снижает риск ошибок перед запуском поля.

## Основные сценарии использования

1. Исследователь загружает draft-версию анкеты.
2. Система анализирует структуру вопросов, варианты ответов, кодировку, стилистику и методологические риски.
3. Пользователь получает отчет по категориям:
   - критические ошибки;
   - важные замечания;
   - рекомендации по улучшению.
4. Для каждого замечания система показывает:
   - фрагмент анкеты;
   - суть проблемы;
   - почему это проблема;
   - как исправить.

## MVP-функции

- drag-and-drop загрузка файлов;
- поддержка DOCX, PDF, TXT;
- извлечение текста из документа;
- AI-проверка анкеты по набору правил для количественных исследований;
- вывод отчета по секциям;
- статус замечаний: Critical / Major / Minor / Recommendation;
- возможность копировать отчет.

## Рекомендуемый стек

- Frontend: Next.js + TypeScript + Tailwind CSS
- Backend: Next.js API routes или Node.js
- AI: LLM через API
- Парсинг файлов: pdf-parse, mammoth, text extraction pipeline
- Хранение: локально для MVP, затем cloud storage

## Что должен уметь сайт

Сайт не просто суммирует документ, а проводит именно профессиональную проверку количественной анкеты. Он должен уметь выявлять:

- дублирование кодов;
- отсутствие варианта «Другое» там, где он методологически нужен;
- отсутствие варианта «Затрудняюсь ответить» или «Не знаю», если это логически ожидается;
- пересечение диапазонов;
- неполное покрытие диапазонов;
- несоответствие вариантов ответа формулировке вопроса;
- наводящие, предвзятые или экспертно некорректные формулировки;
- стилистическую несогласованность обращения «Вы/вы»;
- базовые ошибки анкеты для количественного исследования.

## Как использовать эти файлы

1. Загрузите все файлы в новый GitHub-репозиторий.
2. Откройте файл `04_PROMPT_FOR_AI_DEVELOPER.md`.
3. Передайте его GitHub Copilot / Cursor / Claude Code / другому AI-разработчику.
4. Используйте остальные файлы как продуктовую и методологическую основу.

Сделать рабочий сайт, который принимает анкету и выдает понятный профессиональный отчет по качеству инструмента исследования.
